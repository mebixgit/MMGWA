# mytest

A simple website hosted on GitHub Pages.

## 🌐 Live Website

The website is automatically deployed to GitHub Pages and can be accessed at:
- **URL**: https://mebixgit.github.io/mytest/

## 📝 About

This repository contains a simple static website that demonstrates:
- HTML5 structure
- CSS3 styling
- Automatic deployment via GitHub Actions
- GitHub Pages hosting

## 🚀 Deployment

The website is automatically deployed to GitHub Pages whenever changes are pushed to the `main` branch. The deployment is handled by a GitHub Actions workflow.

## 📂 Project Structure

```
.
├── index.html          # Main HTML file
├── styles.css          # CSS stylesheet
├── .github/
│   └── workflows/
│       └── pages.yml   # GitHub Actions workflow for deployment
└── README.md          # This file
```

## 🛠️ Local Development

To view the website locally:
1. Clone this repository
2. Open `index.html` in your web browser
